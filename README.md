# HATTARI

映画のハッキングシーンを「演奏」したり「鑑賞」したりするブラウザアプリ。
適当にキーボードを叩くだけで、架空のサイバースペースに侵入する映画的な演出が展開されます。

> 実際のネットワーク通信・スキャン・攻撃は一切行いません。画面上のコマンドやログはすべて架空の SF 用語による演出です。

## 起動

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + 本番ビルド
npm test         # 自動テスト（Vitest）
```

## 操作

| 操作 | 内容 |
| --- | --- |
| 適当なキー | コマンドやコードが高速で入力される。速く叩くほど派手になる |
| Enter | 実行。実行中に押すと出力をまとめて流す（ターボ） |
| 連打（実行中） | 処理が加速する。逆探知中は対抗措置になる |
| Backspace | 入力を少し戻す |
| Esc | すぐにデモ（自動操縦）へ切り替える |
| 15 秒放置 | 自動でデモに戻る（キーを叩けば即座に手動へ） |

最初のキー入力かクリックで音が鳴り始めます（ブラウザの自動再生制限のため）。右上の `SND` で消音できます。

## 構成

```
src/
  main.ts      起動・入力・メインループ・各要素の連動
  hack.ts      進行の中核（プロンプト/コード/実行/逆探知/フィナーレ）
  demo.ts      自動操縦。人間と同じ hack.key()/enter() を叩く
  content.ts   コマンド・ログ・コードの素材（架空の語彙）
  terminal.ts  ターミナルの DOM 描画と簡易シンタックスハイライト
  rain.ts      デジタルレイン（Canvas）
  panels.ts    サイドのサブウィンドウ群
  fx.ts        フラッシュ・揺れ・バナー・巨大文字
  audio.ts     Web Audio による効果音合成
  sched.ts     演出タイマーを 1 本の rAF ループに集約
```

入力（手動 / デモ）→ `Hack` が状態を進める → `onPulse` で雨・パネル・音・画面効果が反応、という一方向の流れです。
